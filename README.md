# 💜 Pomodoro e Foco
Este método de estudos ajuda milhares de pessoas ao redor do mundo a trabalharem em suas tarefas com os modos focado e difuso da atenção. 
* Você pode ver tudo funcionando através deste link:
* (https://rochalivia.github.io/pomodoro-foco/)


Além de propor mais produtividade, melhora processos de aprendizagem.

## O que tem aqui
 -- ✅ Explorei com este projeto, uma função nativa muito interessante do #JavaScript, onde conseguimos executar comandos lógicos em um determinado prazo de tempo. O comando setInterval define a lógica do relógio!

--  ✅ Além disso, reforcei os estudos de manipulação do DOM com o document.CreateElement('tagAqui'), criando dinamicamente as tarefas inseridas no form, adicionando assim a lista criada à esquerda.

--  ✅ Também pude conhecer melhor o atributo [data], o qual inserindo no css e no js, foi possível criar a lógica para mudança dos temas coloridinhos ><
